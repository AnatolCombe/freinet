# 01_cadrage — cadrer le sujet avant tout

One job : Fixer ce que la carte couvre, pour qui, et vers quelles quêtes.

## Inputs
- Working : `../00_import/output/source.md` **ou** le sujet nu donné par Marius
- Reference : `../../_config/pedagogie.md` · `../../_config/sources/<domaine>.md`

Do NOT load : les `output/` d'autres runs, les autres étapes, `brainiacs/*/profil/`.

## Process
1. Écrire l'objectif, le périmètre (dedans / dehors), le niveau d'entrée.
2. Proposer 2 à 4 quêtes concrètes (objectif vérifiable).
3. Lister les sources de référence : URLs des domaines de `_config/sources/<domaine>.md` (créer ce fichier si le domaine est nouveau) ou ouvrages « Auteur, Titre (année) ».
4. Viser ~25 concepts ; au-delà, c'est une extension future (B22).

## Outputs
- `cadrage.md` → output/

## Human check
**Gate lourde** : relire le périmètre et les quêtes. C'est ici qu'une correction coûte le moins (courbe en U).
