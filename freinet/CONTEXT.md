# freinet/ — le moteur déterministe

> Code Python 3.12 (PRD A9), resté compatible 3.11 (CI). **Un fichier = une responsabilité, ≤ 400 lignes** (hook god-node).
> **Une seule couche parle à la base : le paquet `freinet/base/`** (inv. 1, A10) — seul à importer `sqlite3` et à exécuter du SQL ; il exporte `ErreurSQLite` pour que les autres n'aient pas à l'importer. Les étapes LLM ne l'importent jamais (inv. 2).

## Règles
- `revue` est la seule vérité ; `fsrs` et `maitrise` sont des caches que `etat.recalculer` réécrit.
- **Les caches sont périmés** dès qu'une revue est ajoutée ou que `_config/regle-acquis.md` change : avant de lire `base.etat()` (sélection) ou de sauvegarder, appeler `etat.recalculer` pour chaque élève concerné. `restauration_valide` exige des caches à jour.
- Une correction de note est une **nouvelle** revue avec `corrige_id` (jamais un UPDATE, inv. 3).
- « Acquis ne recule jamais » vaut pour le journal qui s'allonge : une correction ou une réponse saisie en retard réécrit l'histoire, et le rejeu peut alors redater l'acquisition ou la retirer.
- Un `pre_test` est journalisé mais ne pèse pas sur FSRS (#7).
- `sauvegarde` utilise `os.link` : la destination doit supporter les liens physiques (APFS oui, exFAT non).
- Inspecter la base sans écrire d'écran : `uvx datasette data/freinet.db` (#66, outil de dev).
- La bibliothèque de démonstration des tests vit dans `tests/donnees/bibliotheque/` (carte `harmonie-demo`).
- **Publier** = `freinet.publication.publier` : arbre de préparation (bibliothèque actuelle + sorties du fan-out), `charger` → `erreurs` → `erreurs_contenu` → `concepts_disparus` ; tout vide → échanger, régénérer l'index. Seule voie d'écriture dans `bibliotheque/`. La bibliothèque est cumulative ; un concept ne disparaît que renommé (`alias: [ancien]`).
- Le journal garde le `concept_id` d'origine ; `rejouer`, `recalculer`, `etat_coherent` et `restauration_valide` prennent `canonique` (ex. `Bibliotheque.canonique`) pour regrouper un concept renommé sous un seul état FSRS. **Passer le même `canonique` partout** (le passage du matin passe `bib.canonique`) : des caches écrits avec et vérifiés sans signaleraient une fausse incohérence.
- Références du ticket (#33) : `tests/ticket/reference/` (texte + empreinte du PNG, et le PNG à regarder). Après un changement voulu du rendu : `pytest --update-ref`, puis relire `ticket-demo.png`.
- Tests : le LLM est coupé partout (`tests/conftest.py`, `FREINET_SANS_LLM`) ; `tests/matin/test_coach.py` le remplace par une commande factice. Aucun test n'écrit dans `data/` du dépôt.
- Vérification V0 : `scripts/verif-v0.sh` (scénario `scripts/verif_v0.py`, suite, index, contrats `scripts/verif-contrats.py`).
